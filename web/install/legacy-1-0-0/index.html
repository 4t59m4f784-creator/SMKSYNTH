Depois de instalar

O teclado deve informar SMK-37 Pro_19618. O Pattern 1 abre parado, a 90 BPM. Aperte PLAY para ouvir. KNOB BANK → Patterns dá acesso a P1–P5; P6–P16 estão livres. Os oito pads inferiores de Performance recuperam os favoritos.

Se a transferência for interrompida, volte a esta página pelo mesmo navegador. A retomada fica vinculada ao pacote e à origem V016. Guarde o log se não concluir.
