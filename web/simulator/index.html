EXPERIMENTE

Inicie o simulador e aperte PLAY para ouvir o primeiro exemplo. KNOB BANK percorre Performance → Split/Layer → Patterns. No banco Patterns, toque em P1–P5 para escolher os exemplos. P6–P16 estão livres.

No banco Performance, os oito pads inferiores recuperam seus favoritos. Em uma parte DRUM-X, o ciclo de KNOB BANK acrescenta Drum Pads. Escolher bateria não muda os pads automaticamente.

K1–K4 alteram os controles da tela; K6 escolhe a parte. Para editar a engine, toque GLOBE até PART SETUP e use K1 para escolher ANALOG/DRUM-X. O modo KEY TRANS permanece ativo até ser desligado; K4 na Performance mostra KEY TR quando ligado.

SUA SESSÃO

O simulador usa memória própria deste navegador. Seu teclado físico não é alterado. Faça SAVE no painel para gravar timbres/patterns; exporte a sessão para guardá-la.

Mouse/toque nas teclas e pads; arraste knobs para cima ou para baixo. Teclas A W S E D F T G Y H U J K O L P ; também tocam.
