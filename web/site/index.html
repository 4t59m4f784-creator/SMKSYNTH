01 / A IDEIA

O som vem de projetos excelentes.
A proposta está na experiência.

Do ponto de vista sonoro, o SMKSYNTH é o casamento do excelente sintetizador OberVave com a engine DRUM-X do JIANT.

Porém, um instrumento é muito mais que o som. A ideia é transformar o SMK‑37 Pro em um instrumento voltado para a performance, usando seus pads e controles para alternar partes, acessar favoritos, gravar sequências, criar layers e splits e recuperar cenas.

“Os pads são o coração do SMKSYNTH. Este projeto traduz minha visão de um instrumento para performance nesse formato compacto de 37 teclas.”
Marcus Padrini

02 / PADS PERSISTENTES

Você escolhe o banco.

04 / LEVE PARA O INSTRUMENTO

Primeiro, M‑VAVE V016.
Depois, SMKSYNTH.

O instalador aceita somente SMK-37 Pro_016, a identificação do firmware oficial V016 para SMK‑37 Pro. Instale essa versão pelo M‑UPGRADE do fabricante antes de começar.

Se já usa SMKSYNTH, salve e exporte seu banco antes de retornar ao firmware oficial. A instalação inicial prepara os dados de fábrica e não preserva um banco anterior.
