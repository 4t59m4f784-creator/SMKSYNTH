01 / A IDEIA

O som vem de projetos excelentes.
A proposta está na experiência.

Do ponto de vista sonoro, o SMKSYNTH é o casamento do excelente sintetizador OberVave com a engine DRUM-X do JIANT.

Porém, um instrumento é muito mais que o som. A ideia é transformar o SMK‑37 Pro em um instrumento voltado para a performance, usando seus pads e controles para alternar partes, acessar favoritos, gravar sequências, criar layers e splits e recuperar cenas.

“Os pads são o coração do SMKSYNTH. Este projeto traduz minha visão de um instrumento para performance nesse formato compacto de 37 teclas.”
Marcus Padrini

04 / LEVE PARA O INSTRUMENTO

Instale ou atualize.
Pronto para tocar.

Para a primeira instalação, o instalador exige SMK-37 Pro_016, a identificação do firmware oficial V016 para SMK‑37 Pro. Instale essa versão pelo M‑UPGRADE do fabricante antes de começar.

Se já usa SMKSYNTH, escolha Atualizar para preservar seu banco. Exporte um backup antes. A instalação inicial prepara os dados de fábrica.

05 / CÓDIGO ABERTO

Créditos claros. Fontes disponíveis.

O SMKSYNTH foi desenvolvido com uso de IA. Marcus Padrini definiu os objetivos e o fluxo de performance, orientou o trabalho, selecionou os sons, criou os cinco patterns e realizou os testes e a aprovação no instrumento. O ChatGPT, da OpenAI, contribuiu com propostas e soluções técnicas e gerou e revisou código das adaptações, ferramentas web, documentação e materiais gráficos sob sua orientação.
