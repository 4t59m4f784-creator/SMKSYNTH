# SMKSYNTH 1.0.2

Stereo USB audio tested on Mac and on iPhone with AudioShare. iPhone video recording using USB audio may contain clicks and dropouts; a known issue under investigation.

Áudio USB estéreo testado no Mac e no iPhone com AudioShare. A gravação de vídeos com áudio USB no iPhone pode apresentar cliques e cortes; problema conhecido em investigação.

Install the first-install package only from official SMK-37 Pro V016, or the preserving update over SMKSYNTH. Keep a bank backup. The UA1 experimental package and the 1.0.1 release remain unchanged.
