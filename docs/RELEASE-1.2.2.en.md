# SMKSYNTH 1.2.2 — Endless MIDI

Minor fix for unintended tuning drift in Vintage/Detune patches after returning from MIDI MODE or using MIDI PANIC (GLOBE + PLAY). Voice cleanup preserves each voice’s random generator, preventing progressive pitch drop and preserving oscillator noise.

The TF1 /19654 fix was validated on hardware by a user. Endless MIDI features, edition name and storage format are unchanged. Updating preserves saved programs, patterns, favourites, theme and MIDI maps. First installation still requires model-specific stock V016 and prepares the factory bank.

Identities: SMK-37 Pro_19655 / SMK-37 Elite_19655.
