# SMKSYNTH

**A performance instrument for the M‑VAVE SMK‑37 Pro.**

Its sound comes from OberVave and JIANT's DRUM-X engine. SMKSYNTH focuses on the instrument around them: persistent pad banks, instant favourite sounds, four parts, split/layer configurations, sequencing and scene recall on a compact 37-key keyboard.

Factory setup: five patterns by Marcus Padrini, eight favourites, empty slots 6–16 and a 90 BPM starting tempo. The base preset bank is unchanged. Edited sounds live in scene/favourite snapshots; no extra user presets are installed.

**First installation requires official M‑VAVE V016 on SMK‑37 Pro, identifying as `SMK-37 Pro_016`.** Other models/versions are rejected. This package initializes the bank; it is not a bank-preserving update. Export work before returning to stock. Official M‑VAVE firmware is not redistributed.

DP2 runtime was approved on Marcus's keyboard. The 1.0.0 initial-install package passed simulated-flash tests using the supplied V016 image, including interruption/resume. Marcus subsequently confirmed physical USB first installation on his instrument. The public tools include a PT / EN language selector.
