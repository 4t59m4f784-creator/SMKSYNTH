# SMKSYNTH 1.2.2 — Endless MIDI

Correção mínima para a falha de afinação em timbres com Vintage/Detune ao retornar do MODO MIDI ou usar MIDI PANIC (GLOBE + PLAY). Preserva o gerador aleatório de cada voz durante a limpeza, evitando a queda progressiva de afinação e mantendo o ruído dos osciladores.

Correção TF1 /19654 validada em equipamento por um usuário. Recursos, formato dos dados e nome Endless MIDI mantidos. Atualização preserva programas, patterns, favoritos, tema e mapas MIDI salvos. Primeira instalação continua exigindo V016 oficial do modelo e prepara o banco de fábrica.

Identidades: SMK-37 Pro_19655 / SMK-37 Elite_19655.
