# SMKSYNTH 1.2.0 — ENDLESS + MIDI MODE

Official release for SMK-37 Pro and SMK-37 Elite, promoted from hardware-approved MO1a (/19648). Version 1.2.0 identifies as /19649. Promotion retains the validated behaviour and updates versioning and publication materials.

- **Integrated ENDLESS:** step-entry notes/chords, rests, extensions, direction and HOLD; four parts with independent lengths. C4 is the transposition reference. PARA enables/disables; opening its page does not enable it. REC enters recording; holding REC clears the part. Notes also transmit through USB and TRS/DIN on each part channel.
- **Independent MIDI MODE:** silent synth and USB/TRS controller with four maps, main and per-control channels, accelerated ABS/REL encoders, faders, configurable pads and selectable colours. Edit everything on the instrument. Display includes controls, pads and a 37-key virtual keyboard. No Bluetooth in this release.
- **Optional Zoom theme:** larger labels and values; Obervave remains default. Choose in GLOBE > THEME; saved automatically when audio is quiet. Part colours identify the header line, badge with white letter, and preset number; performance retains its pattern indicator.
- **Dedicated oscilloscope:** short PATCH moves from performance values to logo/scope/voice or drum activity; the next tap enters Mixer. Long PATCH returns to values. Parameter edits briefly appear in a Zoom notice over the scope.
- **Preset names:** short BT saves quickly; long BT opens name and destination. K1 cursor, K2 character, K7 slot. The existing destination program is visible. BT reviews; another BT confirms; PATCH goes back/cancels.
- **Supersaw only on OSC 1 to preserve stability**, with five-voice allocation while SUPER is in use and replacement of release tails. OSC 2 keeps conventional waveforms; older experimental patches with OSC 2 SUPER normalize to SAW on load.
- **Fixes:** MIDI MODE return without freezing or residual modulation; independent fader, encoder, pad and note updates; improved K1–K4 contrast and part colours.

Retained: four-part USB/TRS MIDI OUT (keys, pads, Split/Layer, ARP and sequencers), pitch bend/mod wheel for the selected part, physical sustain with startup polarity detection, and GLOBE + PLAY MIDI PANIC. No outgoing MIDI Clock/Start/Stop or automatic Program Change. iPhone USB video recordings may contain clicks/dropouts.

## Installation and data

One [installer](https://4t59m4f784-creator.github.io/SMKSYNTH/install/?lang=en) identifies Pro/Elite and chooses the package. **Update preserves the saved bank**, including compatible ENDLESS/MIDI/Zoom builds through MO1a. Export a .smksynth backup first. First installation requires the model’s official V016 and initializes the factory bank (five patterns and eight favourites).

A .smksynth backup contains the synth bank; MIDI maps and theme use separate storage and are not included in that file. Resume interrupted older transfers in their original installer before switching versions. The installer retains 1.1.0 resume access.

Marcus approved the MO1a base on Pro hardware. A real user previously validated the Elite installation flow; new packages for both models have automated identity, integrity and bank-protection checks. Promotion to 1.2.0 does not imply a fresh physical test of every package.
