# SMKSYNTH 1.3.1 — Endless MIDI

Maintenance update promoted from hardware-approved PS3 /19667.

- Fixed Endless alignment on pattern changes and preserved the first attack across engine changes, including the kick when entering pattern 1.
- ARP activation no longer cuts the sequencer’s newly triggered first note.
- Fixed reverb output arithmetic overflow and Zoom Mixer edit-popup stacking.

Improved stability during repeated recalls with different BPMs. No new performance features. Approved sound parameters, effects, polyphony, saved-data layout and dual-core architecture are retained. Updating preserves the saved bank, theme and MIDI maps; first installation still requires the correct V016 and seeds the same factory bank.

Identities: SMK-37 Pro_19668 / SMK-37 Elite_19668. The 1.3.0 manual and quick guides remain applicable.
